@creativo/ui/charts — the analytics screen's drawings, hand-drawn SVG and CSS over the DS tokens. Every input is a display struct a presenter built: the kit decides nothing and formats no number. Colour is CSS only — a mark carries data-part and charts.css maps it to a token (fill/stroke, never color); words are ink. Each drawing is role="img" named by uiLabel, with the figures reachable as text. ui-bar-chart, vertical, stacked: the week's days along the baseline, each bar's parts from the baseline out — worked in the accent, no-show in the destructive red, unmarked in amber under a hatch, then the greys 76 / 62 / 48 %. 4 px rounded data ends, 2 px of surface between parts and bars, a hairline edge. The legend is the [uiChartLegend] slot. A tap emits the bar's index; the bars are one tab stop and the arrows walk them. «Друга седмица» swaps the data so the bars glide.

ui-heatmap: weekdays × hours as a CSS grid, each cell with data tinted on the accent at 10–100 % of --ui-cell-strength (value over max), a cell without data in the control fill. Row and column words in ink; the cells are a hidden table for a screen reader. ui-radar: five axes, the first straight up, each vertex at its value's share of the radius.
