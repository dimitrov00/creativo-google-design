ui-async-image — ≙ SwiftUI AsyncImage(url:) { image } placeholder: { … }: a lazily-loaded cover image behind a placeholder surface that cross-fades out when the bytes arrive. Projected [uiPlaceholder] content replaces the default ui-skeleton. The image fades in over the placeholder once it loads. uiRatio takes a raw CSS aspect-ratio — like uiFrame, intrinsic media geometry has no finite semantic scale.

uiSrc: null renders the placeholder permanently (the no-imagery fallback case); a failing source keeps it up too — the surface never collapses or flashes broken-image chrome.
