## Decisions the fixes rest on

1. **No retry list, no `count()`.** (Stage 8 M-A, N-A.) Eligible = missing, version-stale, or inside the window since the last completed pass (from that pass's date minus one day, to today); the full reach only when the job document's recorded version or barber-id list differs. A decisive write failure is the accepted residual beside clock skew: logged with its key, rewritten on the day's next edit or the next version bump. The trigger writes only day documents; the recompute writes only the job document.
2. **No `ANALYTICS_SPAN_UNAVAILABLE`.** (Stage 8 N-B.) With the flag off a long span falls through to the existing `resource-exhausted` refusal and «Опитай по-късно»; the read path's rollback is a redeploy of the previous functions build, the flag is the dark-launch gate.
