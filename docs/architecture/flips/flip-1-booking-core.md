# Flip 1 — booking core (Phase 3b)

**Date:** 2026-10-11 · **Status:** execution plan, the contract the parallel
packages build against. · **Law:** `CLAUDE.md` Laws 1–8 and the seven
`.claude/rules/*.md`; this plan never overrides them. · **Sources:**
`docs/architecture/ecs-migration.md` §3, §4.1, §4.2, §5, §6 Phase 3, §7, §8;
`docs/architecture/flatten-spec.md` (names, §2.3 T1–T9, §5 D29, §6 writes);
`docs/architecture/firestore-runbook.md` (reader matrix, missed readers, gates,
TTL). Line anchors below are omitted on purpose: they move; every file was
located by `git grep` on 2026-10-11 against `c0e5d73` (clean tree).

A flip is the read/write closure of its collections, landed as **one
commit**: pipelines, server adapters, every surviving reader, web bundles,
the consuming store fields, rules, indexes, seed fixtures, the e2e seed and
the P0 proofs. Greenfield: no dual shape, no backfill, no fallback reader; the
emulator is wiped and reseeded.

## 7. Deletions and the edge floors

### 7.1 Deletion rule

A file is deleted in the flip commit when `git grep` shows no importer of it
and `pnpm nx run-many -t typecheck --skip-nx-cache` stays green — never
earlier because a successor exists. The lists of §4 are the files that lose
their last importer **in this flip** (checked against today's import graph:
e.g. `crypto-id-generator.ts` is imported only by `commit-booking.ts`,
`request-waitlist.ts`, `reschedule-appointment.ts`, `match-waitlist.ts`;
`party-admission.ts` only by flip-1 code; `lib/trigger-attempts.ts` and
`lib/ops/work-budget.ts` only by flip-1 handlers). **Survivors, with the
importer that keeps them:** `fn:lib/booking/caller-roles.ts` (+spec) ←
`lib/loyalty/publish-streak-definition.ts` (flip 3);
`fn:lib/booking/tenant-zone.ts` ← `edge.ts`, `main.ts`;
`fn:adapters/system-clock.ts` (+spec) ← `lib/otp/*`, `lib/loyalty/*`;
`fn:test-support/fixed-clock.ts` ← the otp and streak use-case specs;
`fn:test-support/fake-firestore.ts` ← the user/otp repository specs;
`fn:lib/flags.ts`, `fn:lib/firebase-admin.ts`. `libs/application/**` and
`libs/domain/**` files are **not** deleted: their own barrels still export
them (Phase 4); the grep gate proves no `STORE` file imports their flip-1
mappers. Each package re-runs the importer grep for its deletions at
integration; a file that still has an importer stays and is reported.
