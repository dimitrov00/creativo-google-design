# P0 exit-criteria proofs

`pnpm run verify:p0` builds the functions, writes their flag env and runs `verify-p0.mjs` inside fresh firestore, auth, functions and storage emulators. It proves the client-details P0 exit criteria that need the whole stack (design §12.4 P0): the seed runs twice with the same result (appointments, users, client records and stats), a double backfill is byte-equal apart from `updatedAtUtcMs`, the seed's stats equal the backfill's for every client record a seat names (`subjectCustomerIds` → `clientStats/{customerId}`, money in `restricted/money` as `lifetimeSpendCents`), a staff edit of the seeded party of two audits each person (one `BOOKING_STAFF_MOVE` row per person's client record, `targetCustomerId`, actor `ADMIN`), and a profile rename is audited by field name only (`PROFILE_UPDATED`, `profileFields`, targeting the account). Since flip 1 every document it reads is the flat archetype body (Law 5): the backfill's progress is `backfillJobs/clientStats.finishedAtUtcMs` with its `sampleChecked`/`sampleMismatched`, and the party is re-read on `utcEpochMs`, `localDate` and `startMinutes` — only the callable's move payload keeps its frozen wire (`startIso`, an ISO instant with its offset; flip-1 plan F1-3). The script also runs against a live `pnpm run dev` stack (`node tools/verify/p0/verify-p0.mjs`); it rebuilds `clientStats` from scratch and puts back the party and the name it edits. Between steps it waits for the function triggers to go quiet with `tools/seed/settle.mjs`, the same wait the e2e suite runs (as `node tools/seed/settle.mjs`) after its one seed. Each wait counts from the instant its step began, so a trigger the seed or the backfill set off that died before the wait connected is still reported by name.

The settle watches the trigger executions on the Logging emulator, and it refuses to run without one: a wait on the data alone once called a trigger storm quiet. `verify:p0` starts one with `START_LOGGING_EMULATOR=true`, and a live `pnpm run dev` stack has one through `--ui`. The workspace's pinned firebase-tools (a root devDependency, 15.31.0, which every package script runs) also starts it when the variable is unset, but only by accident (the settle's header explains why), so start any other hub with one of the two. Against a hub without a Logging emulator this script fails at its first settle: it offers no data-only opt-out, because its proofs are only as good as the wait. The settle keeps that opt-out for other callers who knowingly accept the weaker wait: `allowDataOnly: true` in process, `--allow-data-only` on its CLI.

The backfill runs loop the `runBackfill` callable the way any runner should. Each call answers within its own work budget (49 s, sized from the callable SDK's 70 s default wait), and the script waits up to 600 s for it, longer than the callable's 540 s platform timeout, so it never abandons a call the server is still working on. If an answer is lost anyway — no answer in time, a dropped connection, or a body that arrives cut off, empty or unreadable (only a well-formed `{error}` is a refusal; see `callable-answer.mjs`, proved by `node --test tools/verify/p0/callable-answer.spec.mjs`) — the script does not re-send the request: it calls again without a cursor, and the server continues from `backfillJobs/clientStats`. The run's totals and its sample are read from that document at the end.

The first proof needs no emulator: `(f)` compares the dependency keys of the functions build's generated `dist/apps/functions/package.json` with `functions-deps.baseline.json` (the ECS migration's Phase 1 gate — a new graph edge, even one from a project's `eslint.config.mjs`, silently grows the deploy's runtime dependencies). It lives in `functions-deps.mjs` (proved by `node --test tools/verify/p0/functions-deps.spec.mjs`) and runs alone after a build: `pnpm nx build functions && node tools/verify/p0/check-functions-deps.mjs`. Re-record the baseline with `--record` only for an intended change, and say why in the commit; the end of Phase 3b re-records it with `@angular/*` and `rxjs` gone.
